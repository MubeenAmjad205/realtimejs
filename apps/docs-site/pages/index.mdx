# Introduction to RealtimeJS

Welcome to **RealtimeJS**! 🚀

RealtimeJS is a framework-agnostic realtime toolkit designed to help developers add realtime capabilities to applications with minimal setup and maximum flexibility. It provides a unified developer layer above various infrastructure providers like Socket.IO, WebRTC, and native WebSockets.

## Why RealtimeJS?

Today, developers often have to manually combine and configure raw WebSockets, Socket.IO, LiveKit, Redis, databases, and UI libraries to build even simple realtime applications. This results in:
- High complexity
- Slow development time
- High maintenance costs

RealtimeJS solves this by providing a complete, plug-and-play toolkit with an **adapter-driven architecture**.

## Core Features

- **Adapter Driven:** Swap between Socket.IO, Native WebSockets, or custom adapters without changing any core business logic.
- **Advanced Chat Mechanics:** Built-in offline queueing, message status tracking, reactions, and editing.
- **Presence & Typing:** Real-time user status tracking and typing indicators.
- **Optimistic UI:** The official React SDK ensures user interactions feel zero-latency while syncing state in the background.
- **100% Type Safe:** Written in strict TypeScript.
